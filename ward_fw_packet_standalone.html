4. Ward Packet Status — all devices

Splits pkt telemetry per day per device: main colored number = live/heartbeat count (pkt == 0, expected ≈ 96/day = 24h × 4 at 15-min intervals); small "+N" = event count (pkt != 0). Coloring is based on the live count only. End date can't be today or later — today's count is still partial and would misleadingly show as low/red. Click any column header to sort by it (click again to reverse) — e.g. sort a day column to group the lowest counts together, then check their Lat/Lon to spot a localized network issue among neighbours.
